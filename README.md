# Site dt.techsolutions

Site institucional da DT Tech Solutions: criação de sites e sistemas, manutenção de PC e suporte técnico.

- `index.html`: estrutura do site
- `style.css`: visual
- `script.js`: animações e botão do WhatsApp
- `Dockerfile` + `nginx/`: servidor para deploy no Railway
